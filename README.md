# NexyonCloud All In One Installer

NexyonCloud Pterodactyl All In One Installer UI.

## Current menu

- Panel Installer
- Wings Installer
- Theme Installer
- Extensions
- Uninstall
- Exit

## Run

```bash
chmod +x install.sh
sudo ./install.sh
```

## GitHub

Upload `install.sh` and `README.md` to your repository.

> Note: The menu currently contains the installer UI. Connect your actual Panel, Wings, Theme, Extensions and Uninstall routines inside the corresponding `case` blocks before using it as a production installer.
